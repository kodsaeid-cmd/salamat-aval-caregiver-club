# باشگاه مراقبین سلامت اول

وب‌اپ یکپارچه عضویت، جذب، آموزش، پایش، ارزیابی و توسعه حرفه‌ای مراقبین سلامت اول.

## وضعیت نسخه اولیه

این نسخه، هسته اجرایی MVP را فراهم می‌کند:

- رابط کاملاً فارسی و RTL با رنگ‌های سازمانی سلامت اول
- داشبورد مدیریت کاربران و نقش‌ها
- ایجاد کاربر سازمانی و تخصیص نقش و مجوز
- نقش «کاربر جذب» و فرم ثبت پروفایل مراقب
- مراحل جذب مراقب از ثبت اولیه تا فعال‌سازی
- فهرست و جست‌وجوی پروفایل مراقبین
- API واقعی کاربران و مراقبین
- مدل داده اولیه برای ارزیابی، آموزش، مدارک و پشتیبانی
- دیتابیس SQLite و Prisma برای توسعه محلی
- Web App Manifest برای نصب‌پذیری وب‌اپ
- CI برای TypeScript و Build

## فناوری‌ها

- Next.js App Router
- React و TypeScript
- Prisma ORM
- SQLite در محیط توسعه
- Zod برای اعتبارسنجی
- CSS اختصاصی بدون وابستگی به قالب آماده

## راه‌اندازی محلی

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:3000
```

## کاربران نمونه

پس از اجرای Seed، کاربران زیر ساخته می‌شوند. رمز عبور نمونه همه کاربران `123456` است.

| نام کاربری | نقش |
|---|---|
| admin | ادمین سیستم |
| recruiter | کاربر جذب |
| operations | مدیر عملیات |
| support | پشتیبان |

> ورود واقعی و مدیریت نشست در گام بعدی تکمیل می‌شود. در نسخه فعلی، تمرکز روی معماری محصول، نقش‌ها، فرم‌ها، API و مدل داده است.

## مسیرهای اصلی

- `/admin/users` — مدیریت کاربران و نقش‌ها
- `/admin/roles` — زیرساخت نقش‌ها و دسترسی‌ها
- `/recruitment/caregivers/new` — ثبت پروفایل مراقب توسط کاربر جذب
- `/caregivers` — فهرست پروفایل مراقبین
- `/evaluations` — ارزیابی و پایش
- `/education` — آموزش و بازآموزی
- `/support` — پشتیبانی باشگاه
- `/reports` — گزارش‌های مدیریتی
- `/settings` — تنظیمات سامانه

## مدل نقش‌ها

- `ADMIN`: مدیریت کامل کاربران، دسترسی‌ها و تنظیمات
- `OPERATIONS`: بررسی و تأیید مراقبین و فرآیندهای عملیاتی
- `RECRUITER`: ثبت و پیگیری پروفایل مراقبین
- `SUPPORT`: مدیریت تیکت‌ها و ارتباط با اعضای باشگاه
- `EVALUATOR`: ثبت و تأیید ارزیابی‌های حرفه‌ای
- `EDUCATION`: مدیریت دوره‌ها، آزمون‌ها و اعتبار آموزشی
- `HR`: کنترل مدارک و وضعیت همکاری

## گام‌های بعدی

1. احراز هویت با شماره همراه و OTP
2. کنترل دسترسی سمت سرور و نشست کاربر
3. آپلود واقعی مدارک در Object Storage
4. موتور ارزیابی و محاسبه امتیاز و رتبه
5. صفحه پروفایل ۳۶۰ درجه مراقب
6. آموزش، آزمون و اعتبار بازآموزی
7. پشتیبانی و تیکت پرونده
8. گزارش مدیریتی و Audit Log

## نکته محیط عملیاتی

برای محیط Production بهتر است SQLite با PostgreSQL جایگزین و فایل‌های مدارک در فضای ذخیره‌سازی سازگار با S3 نگهداری شوند.
