# Professional Scorecard v3

این ماژول، صفحه ارزیابی و پروانه و پرونده حرفه‌ای را با منطق زیر جایگزین می‌کند:

- اسکرول مستقل پنجره امتیازدهی معیارها
- شماره پروانه خودکار برای تمام مراقبین
- حذف PRI و مرجع تصمیم از رابط کاربری
- محاسبه خودکار رتبه از میانگین هشت شاخص حرفه‌ای
- نمایش کارنامه حرفه‌ای مشترک در پنل مدیر و مراقب
