# Mobile Integrity V3

- Replaces the fragile mobile navigation v2 runtime.
- Uses stable canonical route ids and a direct admin fallback for `کاربران و دسترسی‌ها`.
- Handles pointer, click, keyboard and rapid sequential taps.
- Repairs stale backdrop, scroll lock, inert, duplicate shell and busy state.
- Re-annotates data tables after every mobile route transition.
- Applies the official Salamat Aval palette: Eden Green `#185B38` as the dominant color and Red Alert `#D83429` only as an accent or warning.
- Keeps all rules scoped to screens at or below 760px; desktop remains unchanged.
