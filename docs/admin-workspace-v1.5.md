# پنل عملیاتی مدیر سامانه — نسخه 1.5

این انتشار ماژول‌های تزئینی پنل مدیر را با جریان‌های ثبت، ویرایش، تأیید، گزارش‌گیری و Audit Log جایگزین می‌کند.

- کاربران و دسترسی‌ها
- پرونده مراقبین
- قراردادها
- حقوق و پرداخت
- بانک آموزش و تخصیص
- ارزیابی، رتبه و پروانه
- پشتیبانی و امنیت
- گزارش‌ها و خروجی CSV/JSON
- تنظیمات و Audit Log
- همگام‌سازی نام و تصویر مراقب با پروفایل در تمام صفحات
